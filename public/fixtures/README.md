# V0-02 Fixture Assets

The product photographs in `products/` were generated specifically for the
V0-02 interface fixture on 2026-08-14 using OpenAI's built-in image-generation
tool. They depict fictional, unbranded products and are UI test assets—not
product evidence, retailer content, or representations of real listings.

The shared prompt direction was: editorial 4:3 studio product photography of
one original, unbranded consumer object on a warm limestone/off-white set,
soft directional daylight, restrained shadows, premium catalogue composition,
no people, logos, text, watermark, or recognisable trademark design. Separate
variants specified a lightweight running cap, slim open shelving unit, or
over-ear commuter headphones and their fixture colour/material.

The interface fonts come from the npm `@fontsource-variable/inter` and
`@fontsource-variable/newsreader` packages. Both distribute the font files
under the SIL Open Font License; their package license files remain the source
of record.
